Einstellungen

Wird nur in diesem Browser gespeichert.

Die Spielesuche nutzt Wikidata und Wikipedia und funktioniert ohne Key. Mit einem RAWG-Key wird zusätzlich RAWG durchsucht: mehr kleine Indie-Spiele und ein Platzhalterbild.

So bekommst du einen RAWG-Key

  1. rawg.io öffnen und kostenlos registrieren.
  2. rawg.io/apidocs öffnen und auf „Get API Key“ klicken.
  3. Das Formular ausfüllen. Als Website reicht z. B. http://localhost.
  4. Den angezeigten Key kopieren, hier einfügen und sichern.

Alle Quellen werden bei jeder Suche live abgefragt. Neue Spiele sind sofort auffindbar, ein Aktualisieren ist nicht nötig.
